# 五年財務預估與銀行報表編修 App — 規劃書

> 版本：v0.1（第一版實作範圍）　適用對象：台灣公司財務主管個人使用，一個專案編製一家公司。

---

## 0. 設計原則

| 原則 | 落實方式 |
|---|---|
| 單一計算來源 | 所有預估數由同一個「計算圖」（Formula Graph）產生。App 畫面上的數字與匯出 Excel 的公式來自同一份公式定義，因此 App 與 Excel 的計算慣例必然一致。 |
| 可追溯 | 每個儲存格標記為 **實際數／假設輸入／自動計算／手動覆寫** 之一；點選任一預估數可看到公式、引用來源與數值。 |
| 不用平衡數 | 現金由現金流量表推得，資產負債表**不設任何插補科目**。資產≠負債＋權益時，直接列出年度與差額，不自動調整。 |
| 零值須有來源 | 必要假設留白時，該假設以紅色標示「未完成」，並把受影響的科目、報表標為「未完成」。報表狀態顯示「草稿」。 |
| 資料不外傳 | 純前端 App，資料存於瀏覽器 IndexedDB；匯入、計算、匯出都在本機完成，不呼叫雲端或 AI 服務。另可匯出 JSON 備份檔自行保管。 |

## 1. 架構

```
┌──────────────────────── 瀏覽器（本機） ────────────────────────┐
│  UI（React）                                                   │
│   專案清單 → 專案設定 → 基期資料/對應 → 假設 → 固定資產 → 融資 │
│   → 報表/追溯/覆寫 → 勾稽與現金警示 → 情境比較 → 銀行版 → 匯出 │
│                                                                │
│  Domain                                                        │
│   project.ts   專案、情境、版本、修改紀錄資料模型               │
│   coa.ts       EAS 預設科目表（分類、表達、現金流量分類）       │
│   importer.ts  Excel/CSV 解析、科目自動對應、異常偵測          │
│   model.ts     依專案＋情境建立「計算圖」（列 × 年度欄）        │
│   graph.ts     運算式 AST、求值、未完成傳遞、追溯文字          │
│   statements.ts 四大報表版面定義、勾稽檢查、現金警示            │
│                                                                │
│  Export                                                        │
│   excel.ts     計算圖 → .xlsx（公式、樣式、資料驗證、註解）    │
│   print.css    銀行版 A4 列印版面（瀏覽器「另存 PDF」）         │
│                                                                │
│  Storage：IndexedDB（idb-keyval）；JSON 備份匯出/匯入          │
└────────────────────────────────────────────────────────────────┘
```

### 1.1 計算圖（核心）
* **列（Row）**：一個科目或一項假設，屬於某工作表（假設、基期、營收成本、營運資金、固定資產、借款、所得稅及權益、四大報表、勾稽）。
* **欄（Column）**：`[前期比較(可選)…, 基期, 預估第1年…第N年]`。
* **儲存格**：`actual`（歷史實際）、`input`（假設輸入；可為空白＝未完成）、`formula`（運算式）、`override`（覆寫值，保留原公式）。
* 運算式支援 `+ − × ÷`、`SUM/MIN/MAX/IF/ISBLANK/ABS/ROUND`、比較運算及文字常數。App 以 JavaScript 求值，Excel 匯出時轉成對應儲存格公式。
* 方法選擇（例如「週轉天數／占比率」）也是 Excel 中的輸入儲存格（下拉清單），公式以 `IF` 判斷，所以使用者在 Excel 切換方法也會重算。

## 3. 輸入欄位

### 3.1 專案層級
公司名稱、統一編號（選填）、基期年度（如 2025）、會計年度結束月日（預設 12/31）、預估年數 N（1–10，預設 5）、幣別（預設 TWD）、顯示單位（元/千元）、現金警示門檻、借款/還款預設月份、利息分類（營業/籌資，預設營業）、股利支付分類（籌資）、折舊費用歸屬費用科目（預設管理費用）、各報導年度準則版本與適用日期。

### 3.2 情境假設（皆可逐年設定）
| 群組 | 欄位 |
|---|---|
| 營收成本費用 | 營收成長率；毛利率；毛利率/費用率是否已含折舊（含/不含）；折舊分攤至營業成本比率；推銷、管理、研發、其他營業費用占營收比率 |
| 營運資金 | 應收帳款：方法（週轉天數/占營收比率）＋參數；存貨：方法（週轉天數/占銷貨成本比率）＋參數；應付帳款：方法＋參數＋計算基礎（進貨額/銷貨成本〔概估〕）；計算天數基礎（365） |
| 其他損益科目 | 方法（手動金額/固定金額/成長率/占營收比率/占成本比率）＋參數；利息收入另可選「期初現金×利率」 |
| 其他資產負債科目 | 方法＋參數；現金流量分類（營業/投資/籌資） |
| 所得稅 | 方法（稅率估算/手動稅額）、稅率（預設 20%）、稅前損益調整、手動稅額、暫繳比例（以前一年度稅額計，預設 50%）、基期可扣除虧損 |
| 權益 | 現金增資（股本面額部分、溢價部分）、現金股利宣告數、當年度支付比例、其他綜合損益 |

### 3.3 固定資產（類別：土地、房屋及建築、機器設備、運輸設備、辦公設備、租賃改良、其他設備、未完工程及待驗設備）
* 基期：原始成本、累計折舊、累計減損、帳面淨額；餘額性質（總額/僅淨額）。
* 既有資產折舊：「逐年手動輸入」或「估算＝(可折舊淨額−殘值)/剩餘耐用年限」，標示為概估。
* 新增資產（逐年）：資本支出認列額、可供使用月份、耐用年限、殘值率、當年度付款額、由在建工程轉入額。
* 處分/報廢（逐年）：除列成本、除列累計折舊、處分價款、當年度收現、處分後減少之折舊。
* 減損（逐年）：減損損失。

### 3.4 借款（每筆）
名稱、類型（短期/長期）、基期餘額、逐年：利率、新增借款金額與月份、還款金額與月份、年末應付利息月數；最末年之次年度到期還款額（流動分類用）。

## 4. 計算公式（t = 預估年度，t−1 = 前一年度；基期為 t=0）

### 4.1 損益
* 營收ₜ = 營收ₜ₋₁ ×（1＋成長率ₜ）
* 折舊ₜ = 各類別既有資產折舊＋新增資產折舊 − 處分減少折舊
* 含折舊時：銷貨成本ₜ = 營收ₜ ×（1−毛利率ₜ），其中折舊 = 折舊ₜ × 分攤比率（拆分顯示，不另加）
* 不含折舊時：銷貨成本ₜ = 營收ₜ ×（1−毛利率ₜ）＋ 折舊ₜ × 分攤比率（報表毛利率會低於輸入值，畫面提示）
* 營業費用科目ₜ = 營收ₜ × 費用率ₜ；折舊歸屬科目於「不含折舊」時另加 折舊ₜ ×（1−分攤比率）
* 財務成本ₜ = Σ借款利息ₜ；其他利益及損失另加 處分損益ₜ − 減損損失ₜ
* 所得稅ₜ（稅率法）= MAX(0, 稅前淨利ₜ＋調整ₜ − 可用虧損扣除ₜ) × 稅率ₜ
* 本期綜合損益 = 本期淨利 ＋ 其他綜合損益

### 4.2 營運資金
* 應收帳款ₜ = 營收ₜ × 天數/365 或 營收ₜ × 比率
* 存貨ₜ = 銷貨成本ₜ × 天數/365 或 × 比率
* 進貨額ₜ = 銷貨成本ₜ − 營業成本中折舊ₜ ＋ 存貨ₜ − 存貨ₜ₋₁
* 應付帳款ₜ = 基礎ₜ × 天數/365 或 × 比率；基礎＝進貨額，或銷貨成本（標示「概估」）

### 4.3 固定資產（直線法）
* 新增資產（第 k 年取得、可用月份 m）：年折舊 = 成本×(1−殘值率)/耐用年限
  * t=k：MIN(年折舊×(13−m)/12, 可折舊額)；t>k：MIN(年折舊, 可折舊額 − 已提列)
* 成本ₜ = 成本ₜ₋₁ ＋ 資本支出ₜ ＋ 在建工程轉入ₜ − 處分成本ₜ
* 累計折舊ₜ = 累計折舊ₜ₋₁ ＋ 折舊ₜ − 處分累計折舊ₜ；累計減損ₜ = 累計減損ₜ₋₁ ＋ 減損ₜ
* 處分損益ₜ = 處分價款ₜ −（處分成本ₜ − 處分累計折舊ₜ）
* 應付設備款ₜ = 應付設備款ₜ₋₁ ＋ 資本支出認列ₜ − 付款ₜ；應收處分價款同理
* 投資活動現金流出 = 付款額；流入 = 處分收現額

### 4.4 借款（計息慣例：月初生效，期間＝13−月份；月份留白採預設月份，初始 7 月＝半年）
* 利息ₜ = 期初餘額×r ＋ 新增×r×(13−m₁)/12 − 還款×r×(13−m₂)/12
* 期末餘額 = 期初 ＋ 新增 − 還款
* 應付利息ₜ = 期末餘額 × r × 年末應付利息月數/12；付息ₜ = 利息ₜ ＋ 期初應付利息 − 期末應付利息
* 長期借款一年內到期部分ₜ = MIN(期末餘額, 次年度還款額)

### 4.5 所得稅與權益
* 暫繳ₜ = 暫繳比例 × 所得稅ₜ₋₁；應付所得稅ₜ = 所得稅ₜ − 暫繳ₜ（負數表示預付，列資產）；付稅ₜ = 期初應付 ＋ 暫繳ₜ
* 股本ₜ = 股本ₜ₋₁ ＋ 增資面額；資本公積ₜ = ＋增資溢價；保留盈餘ₜ = ＋本期淨利 − 宣告股利；其他權益ₜ = ＋其他綜合損益
* 應付股利ₜ = 期初 ＋ 宣告 − 支付；支付 = 期初應付 ＋ 宣告 × 當年度支付比例

### 4.6 現金流量表（間接法）
營業：稅前淨利 ＋ 折舊 ＋ 減損損失 − 處分利益 ＋ 利息費用 − 利息收入 ± 營業性資產負債變動（應收、存貨、應付及分類為營業之其他科目）＋ 收取利息 − 支付利息 − 支付所得稅
投資：− 取得不動產廠房及設備付款 ＋ 處分收現 ± 投資類其他科目變動
籌資：＋ 新增借款 − 償還借款 ＋ 現金增資 − 發放現金股利 ± 籌資類其他科目變動
期末現金 = 期初現金 ＋ 本期現金增減（不直接取自資產負債表，作為勾稽）

## 5. 勾稽檢查

| 檢查 | 條件 |
|---|---|
| 資產負債平衡 | 資產總額 − 負債總額 − 權益總額 = 0 |
| 現金勾稽 | 現金流量表期末現金 = 資產負債表現金 |
| 權益勾稽 | 權益變動表期末權益 = 資產負債表權益 |
| 期初銜接 | 各年度期初現金/權益 = 前一年度期末 |
| 固定資產 | 期初淨額＋增加−折舊−減損−處分淨額 = 期末淨額；基期類別合計 = 資產負債表金額 |
| 借款 | 各筆借款合計 = 資產負債表短期借款＋長期借款（含一年內到期） ；還款不超過可還餘額 |
| 損益→權益 | 本期淨利 = 保留盈餘變動 + 股利 |
| 基期匯入 | 明細合計 = 原表小計/合計；未對應、重複、格式錯誤、借貸符號異常 |
| 未完成 | 必要假設空白 → 列出年度、假設、受影響科目 |
| 現金警示 | 預估年末現金 < 門檻：顯示年度、現金、差額；現金 < 0：資金缺口 |

容許誤差 0.5 元（四捨五入差異）。

## 7. 尚未指定事項：影響與預設選項

| 事項 | 對數字或送件的影響 | 預設（可調） |
|---|---|---|
| 借款生效月份計息慣例 | 影響當年利息約 1/12 × 金額 × 利率 | 月初生效，期間 13−月；預設 7 月 |
| 利息收付現金流量分類 | 影響營業與籌資現金流量小計，不影響淨增減 | 營業活動 |
| 所得稅繳納時點 | 影響各年度年末現金與應付所得稅 | 暫繳 50% × 前一年度稅額，餘額次年 5 月繳納 |
| 虧損扣除 | 影響稅額與淨利 | 啟用；基期可扣除虧損由使用者輸入（預設 0，需確認） |
| 未分配盈餘加徵 5% | 影響稅費用與現金 | 不自動計算，可用「稅前調整/手動稅額」補入 |
| 法定盈餘公積提列 | 不影響權益總額，僅影響保留盈餘內部明細 | 第一版不拆分 |
| 其他資產負債科目預設方法 | 影響現金及資產總額 | 「固定金額（同前一年）」，於勾稽頁列為「待確認」直到使用者確認 |
| 其他損益科目預設方法 | 影響淨利 | 留白＝未完成，需使用者指定 |
| 遞延所得稅 | 第一版保留基期餘額不變 | 提示銀行版使用者補入調整 |
| 折舊方法 | 第一版新增資產僅直線法 | 其他方法可用既有資產手動折舊替代 |
| 舊版 .xls 匯入 | 無法直接讀取 | 請另存為 .xlsx 或 .csv |

### 8.2 第三階段新增說明
* **財務比率**（App「四大報表」分頁、Excel「財務比率」工作表含公式、銀行版列印可選附）：營收成長率、毛利率、營業利益率、稅後淨利率、EBITDA、ROE、ROA、流動比率、速動比率、應收／存貨／應付週轉天數、負債比率、負債對權益比率、有息負債、淨借款、利息保障倍數、有息負債÷EBITDA、償債保障比率（DSCR＝(EBITDA−支付所得稅)÷(償還借款＋支付利息)）、營業現金流量÷流動負債。分母為零顯示「—」；需前期資料者於最早年度顯示「無前期資料」；基期 EBITDA 須補入基期現金流量表折舊。週轉天數採期末餘額。
* **情境比較圖表**：營收、本期淨利、年末現金（含門檻參考線）、借款餘額之折線圖，單一 y 軸，固定顏色順序，滑鼠移入顯示各年度數值；完整數字以表格呈現。
* **輸入合理性檢查**：月份須為 1–12、比例須介於 0%–100%（錯誤）；毛利率、成長率、費用率、稅率、利率、週轉參數、耐用年限及負數金額超出常見範圍時列為待確認。
* **進度總覽**：各編製步驟之完成狀態與待處理數量，以及最末預估年度營收、淨利、借款餘額與預估期間最低年末現金。

### 8.1 第二階段新增說明
* **增資收現時點**：「增資款當年度收現」留白＝同認列額。收現早於認列列為「預收股本」（權益），晚於認列為負數（應收股款）。現金流量表籌資活動依實際收現列示，權益變動表另列差額。
* **貼上假設**：在任一假設輸入格貼上自 Excel 複製之多格資料（Tab 分欄、換行分列），依序填入右方年度及下方假設列。百分比列接受「8%」、「8」或「0.08」。
* **復原／重做**：保留最近 50 步；連續輸入同一欄位合併為一步；快捷鍵 Ctrl+Z／Ctrl+Y（游標在輸入框內時保留輸入框本身之復原）。
* **逐筆固定資產明細**：匯入財產目錄（欄位自動辨識：類別、名稱、取得日期、成本、累計折舊、累計減損、殘值、耐用年限、剩餘耐用年限；支援民國年及 Excel 日期序號）。類別依名稱關鍵字判斷並可調整。該類別基期餘額改以明細加總，既有資產折舊＝(成本−累計折舊−累計減損−殘值)÷剩餘耐用年限（直線法，累計不超過可折舊額）。剩餘耐用年限推算順序：明細提供 → 耐用年限減已使用年數（至基期末）→ 依未折減比例概估。Excel 另含「固定資產明細」工作表，修改明細亦可重算。

### 8.3 第四階段新增說明
* **讀回 Excel 修改**（匯出頁）：匯出之 Excel 每張計算工作表含隱藏「列代碼」欄，封面記錄專案及情境代碼。讀回時依列代碼與年度欄比對：
  * 假設輸入格數值或選項變更 → 「修改假設」；選項不在清單內或改為公式 → 「無法套用」。
  * 來源科目之公式被改為數值 → 「手動覆寫」（保留原公式）；數值與公式結果相同者（僅貼上數值）不列入。
  * 合計或連動數被改為數值 → 「無法套用」，提示於來源科目修改。
  * 覆寫值改回公式 → 「恢復公式」。
  * 檔案來自其他專案或情境時提示；差異清單逐項勾選後套用至目前情境，可復原。科目名稱、新增列、公式內容修改不讀回。
* **基期現金流量表匯入**：依關鍵字將原表科目對應至現金流量表各列（可調整或略過），多科目對應同一列時加總；以原表營業、投資、籌資小計核對明細合計並顯示差額。
* **整欄貼上**：基期現金流量表及權益變動表可自 Excel 複製一欄數字，貼到第一格後依序填入下方各列。

### 8.4 第五階段新增說明
* **加密備份**：匯出頁可下載加密備份（AES-GCM 256，金鑰由密碼經 PBKDF2-SHA256 310,000 次推導，隨機 salt 及 IV），全程於本機瀏覽器執行；密碼不儲存、不傳送，遺失無法還原。專案清單匯入時自動辨識加密檔並要求密碼；本機已有同一專案時先確認是否覆蓋。
* **銀行版 Excel 隱藏零值科目**：四大報表及財務比率中，全部年度皆為零之明細列設為隱藏（公式保留），與 PDF 版面一致；之後在 Excel 修改使該列不為零時，需自行取消隱藏。
* **情境假設差異**：情境比較頁列出所勾選情境間不同之假設輸入及覆寫值（以第一個情境為基準）。
* **版本比較**：版本頁可將保存之版本與目前版本比較同一情境之營收、本期淨利、年末現金、借款餘額、權益總計及假設差異。基期資料之修改反映於關鍵數字差異，不逐項列示。

### 8.5 第六階段新增說明
* **銀行報表格式**：銀行無指定格式，沿用現行版式。金額單位可選新台幣元或千元：
  * 千元為顯示格式（Excel 以 `#,##0,` 顯示，儲存格仍為元；App 與 PDF 於顯示時四捨五入），所有計算仍以元為準。
  * 各數字個別四捨五入，合計數與明細加總可能有尾差；PDF 及 Excel 正式報表註記「金額以新台幣千元表達，因四捨五入，合計數與明細加總可能有尾差」，不以調整數字消除尾差。
* **基期權益變動表匯入（矩陣格式）**：
  * 欄＝權益組成：股本、資本公積、預收股本、法定盈餘公積、特別盈餘公積、未分配盈餘（三者合計為保留盈餘；另有「保留盈餘合計」欄時僅供核對）、其他權益、庫藏股票、權益總額（核對用）。
  * 列＝變動項目：期初餘額、提列法定／特別盈餘公積（保留盈餘內互抵，合計須為 0）、現金股利、本期淨利、本期其他綜合損益、本期綜合損益總額（略過）、現金增資、其他、期末餘額（核對用）。
  * 無法歸類之變動計入各組成之「其他變動」列（預估年度為 0）。欄列對應可逐一調整。
  * 可下載範本，期末餘額依基期資產負債表預填。匯入時逐欄核對「期初＋變動＝期末（資產負債表）」，不一致者列入勾稽提示。
* **修正**：金額解析之負號判斷原誤為字元範圍，致「-10000000」形式之負數被判為格式錯誤（括號及 △ 不受影響），已修正並補測試。

### 8.6 數字表達慣例
* **金額之負數或減少數以括號表示**，例如 (1,234)；零值金額顯示「-」。適用於 App 報表、金額輸入框、檢查訊息之金額、圖表金額座標與提示框、PDF 及 Excel 金額格式（`#,##0;(#,##0);"-"`，千元為 `#,##0,;(#,##0,);"-"`）。
* **百分比、倍數、比率、天數、月份、年限以負號表示**，例如 -3.00%、-1.50 倍。
* 「其他科目參數」可為金額或比率：絕對值 1,000 以上視為金額（括號），以下視為比率（負號）；Excel 依匯出時之數值個別設定儲存格格式。
* 輸入時可使用 -1,234、(1,234) 或（1,234）表示負數；匯入檔案另支援 △、▲ 及尾端負號。
* 匯入對應表之「原始金額」保留原檔文字，不轉換格式。

### 8.7 穩健性與資料安全
* **壓力測試**：以 500 組隨機假設（含負成長、負毛利、虧損與虧損扣除、處分與減損、增資收現時點、大額借還款、1–8 年預估、覆寫）驗證每一年度資產負債平衡、現金、權益、期初銜接、損益與固定資產勾稽皆通過；另抽 3 組隨機專案以 LibreOffice 重算 Excel，逐格比對與 App 一致。
* **參數誤植檢查**：其他科目方法為成長率或比率而參數大於 10 時列為錯誤（多為誤把金額填入比率），避免數值以倍數爆增。
* **持久儲存**：開啟 App 時向瀏覽器申請持久儲存，專案清單顯示是否取得及使用量；未取得時提醒定期備份。
* **資料版本轉換**：專案記錄資料版本；開啟舊專案、匯入舊備份或還原版本時自動補齊新欄位。
* **錯誤防護**：單一頁面發生錯誤時顯示說明，可復原最近一次修改或回到進度總覽，資料不受影響。
* **窄螢幕版面**：寬度 900px 以下時選單收合於頂端列，報表於框內左右捲動並固定科目欄；已於平板及手機尺寸檢查無頁面水平溢出。

### 8.8 操作環境
* 以電腦版（桌機、筆電瀏覽器）為主要操作環境；平板與手機維持可瀏覽、不跑版，不另行最佳化。
* 輸入表格支援類似 Excel 之鍵盤操作：Enter／Shift+Enter 移至下／上一列同年度，↑↓ 換列，游標位於數字首尾時 ←→ 移至相鄰年度，Tab 往右；移入後直接輸入即覆蓋原值。
* 所有表格左右捲動時固定項目欄。
* **快速鍵**：Alt＋0 進度總覽、1 專案設定、2 基期資料、3 逐年假設、4 固定資產、5 融資、6 四大報表、7 勾稽與現金警示、8 情境比較、9 銀行版編修（輸入中亦可使用；Ctrl＋數字保留給瀏覽器切換分頁）；Ctrl＋Z／Ctrl＋Y 復原／重做。
* **公式追溯面板**：可拖拉左緣調整寬度（280–900px），寬度記錄於此瀏覽器。
* **即時摘要**（螢幕寬度 1400px 以上，逐年假設／固定資產／融資頁右側）：各預估年度營業收入、毛利率、本期淨利、年末現金（低於門檻紅字）、借款餘額、負債比率、償債保障比率及勾稽狀態，金額以百萬元精簡顯示；修改假設後變動之數字短暫以底色標示。可隱藏，偏好記錄於此瀏覽器。

### 8.9 實務版式實測與發行
* **會計師查核報告版式匯入**：自動辨識代碼欄、% 欄、附註欄、兩個年度金額欄（民國年→西元）、表頭金額單位（千元／百萬元）、報表類型；分類標題列（無金額）自動略過；損益表以括號表示費用時自動辨識慣例，不逐筆警告；同一張表之前期金額欄可同時匯入為前期比較；同一檔案多張工作表可連續匯入。
* **補強科目對應**：負債準備、採用權益法認列之關聯企業損益份額、確定福利計畫之再衡量數、國外營運機構財務報表換算之兌換差額等。
* **修正**：前期比較欄僅檢查資產負債平衡（排程類勾稽不適用）；資產負債表權益段不重複列示小計。
* **端到端實測**（`npm run e2e`）：建立專案 → 匯入兩張工作表（含前期）→ 固定資產（僅淨額）、借款、逐年假設 → 四大報表勾稽全數通過 → 匯出 Excel（LibreOffice 重算 1,472 個公式、0 錯誤值、勾稽 45 項通過）→ 銀行版 PDF → 重新整理後資料保留。
* **發行**：`npm run build:app` 產出單一 HTML 檔（約 1.3 MB），以 file:// 直接開啟亦可完整運作。
