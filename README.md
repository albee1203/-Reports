# 五年財務預估與銀行報表編修 App

台灣公司財務主管個人使用的五年財務預估工具。從一個基期年度的「全年損益表」及「年末資產負債表」開始，產生四大報表、勾稽檢查，並匯出含公式、可重算的 Excel。另可編修銀行送件版，並列印成 A4 PDF。

完整規劃請見 [docs/規劃書.md](docs/規劃書.md)，內容包括架構、畫面、輸入欄位、公式、勾稽、Excel 工作表設計，以及尚未指定事項的影響與預設選項。

## 直接使用（不需安裝）

下載 `release/` 資料夾中的 `五年財務預估App_v*.html`，用 Chrome 或 Edge 開啟即可。
* 不需安裝、不需網路，所有資料只存在這台電腦的瀏覽器中。
* 請固定用同一個瀏覽器開啟同一個檔案位置；換瀏覽器或清除瀏覽器資料會看不到原專案，請定期在「匯出」頁下載備份（可加密）。
* 列印 PDF 時請選 A4、取消「頁首及頁尾」。

## 開發

```bash
npm install
npm run dev        # 開發模式，瀏覽器開啟顯示之網址
npm run build      # 產生靜態檔於 dist/，可直接以任何靜態伺服器開啟
npm test           # 單元、壓力（500 組隨機）與 Excel 公式一致性測試（需安裝 LibreOffice）
npm run build:app  # 產出單一 HTML 檔 App 至 release/
npm run e2e -- release/<檔名>.html   # 端到端實測（會計師版式財報 → 匯出 Excel／PDF）
```

## 資料保護
* 純前端 App。專案存在瀏覽器的 IndexedDB，匯入、計算及匯出都在本機完成，不呼叫任何雲端或 AI 服務。
* 清除瀏覽器資料會刪除專案，請用「備份」功能定期匯出 JSON。

## 設計重點
* **單一計算來源**：App 畫面的數字與 Excel 公式都由同一個計算圖（`src/engine/model.ts`）產生。測試會用 LibreOffice 重算匯出的 Excel，逐一比對 1,286 個公式儲存格的結果與 App 是否一致，也會驗證在 Excel 修改假設後，各項勾稽仍然通過。
* **不使用平衡數**：現金由現金流量表推得，資產負債表不設插補科目。有差異時，列出年度、科目及原因。
* **四種儲存格狀態**：歷史實際數、使用者假設、自動計算、手動覆寫（保留原公式）。必要假設留白時，標示為未完成及受影響的科目。
