五年財務預估與銀行報表編修 App　使用說明
==========================================

【開啟】
1. 將壓縮檔解壓縮（在 zip 檔上按右鍵 →「解壓縮全部」）。
2. 用 Chrome 或 Edge 開啟「五年財務預估App_v*.html」：
   在檔案上按右鍵 →「開啟檔案」→ 選 Google Chrome 或 Microsoft Edge。
3. 看到「五年財務預估與銀行報表編修」首頁即可開始使用。

【若雙擊後被其他程式開啟（例如記事本）】
在檔案上按右鍵 →「開啟檔案」→「選擇其他應用程式」→ 選 Chrome 或 Edge，
並勾選「一律使用此應用程式開啟 .html 檔案」。

【資料儲存】
- 所有財報資料只儲存在這台電腦的瀏覽器中，不會上傳至任何網站或 AI 服務。
- 在 Chrome／Edge 中，HTML 檔可以移動位置、改檔名或以新版取代，原有專案仍會保留。
- 以下情況會看不到原專案，請先在 App「匯出」頁下載備份（可加密），再到首頁「匯入專案備份」還原：
  換電腦、換瀏覽器、清除瀏覽器資料、使用無痕視窗。
- 建議固定使用 Chrome 或 Edge；Firefox、Safari 對本機檔案之儲存規則較嚴格。

【列印 PDF】
銀行版編修 →「預覽列印版面」→「列印／另存 PDF」，紙張選 A4，取消勾選「頁首及頁尾」。

【更新版本】
下載新版後，直接開啟新版 HTML 檔即可，原有專案會自動沿用；舊版檔案可刪除。
